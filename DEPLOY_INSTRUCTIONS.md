# 🚀 DEPLOY TAMRAKAR COMPLEX NOW!

## Since we can't use CLI directly, here's the EASIEST deployment method:

### **Step 1: Manual GitHub Upload (5 minutes)**

1. **Create GitHub Repository**
   - Go to [github.com](https://github.com)
   - Click "New repository"
   - Name: `tamrakarcomplex`
   - Public or Private (your choice)
   - Click "Create repository"

2. **Upload Your Files**
   - Click "uploading an existing file"
   - Drag and drop ALL files from `/Users/sc/analise/tamrakarcomplex/`
   - Include hidden files like `.env.example`, `.gitignore`
   - Commit changes: "Deploy Tamrakar Complex"

### **Step 2: Deploy on Vercel (2 minutes)**

1. **Go to Vercel**
   - Visit [vercel.com](https://vercel.com)
   - Click "Sign up" or login
   - Click "New Project"

2. **Import Repository**
   - Find your `tamrakarcomplex` repository
   - Click "Import"
   - Vercel will auto-detect Next.js settings

3. **Set Environment Variables**
   ```
   DATABASE_URL=postgresql://user:pass@host:port/db
   JWT_SECRET=your_very_secure_random_secret_key_123456789
   ADMIN_EMAIL=admin@tamrakarcomplex.com
   ADMIN_PASSWORD=your_secure_admin_password
   ```

4. **Deploy!**
   - Click "Deploy"
   - Wait 2-3 minutes
   - Your site goes live!

### **Step 3: Setup Database (Recommended)**

**Option A: Vercel Postgres (Easiest)**
- In Vercel dashboard → Storage → Create Postgres
- Copy connection string
- Update `DATABASE_URL`

**Option B: Keep SQLite (Quick Start)**
- Use existing SQLite file
- Good for testing
